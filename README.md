# 🌐 DNS Peek

> Узнай, где на самом деле находится сайт, который ты открыл.

**DNS Peek** — расширение для **Firefox**, которое показывает техническую информацию о текущем сайте: IP-адреса, DNS-записи, провайдера, геолокацию и наличие CDN.

Проект создан в учебных целях для изучения **DNS, браузерных расширений, сетей и JavaScript**.

---

## ✨ Возможности

DNS Peek умеет показывать:

* 🌍 IPv4 и IPv6 адреса
* 🏢 ASN / ISP / хостинг-провайдера
* 📍 страну и город
* 🔒 использование CDN
* 📡 CNAME-записи
* 📧 MX-записи
* 📝 TXT-записи
* 🕘 локальную историю проверок
* 📋 копирование IP
* 📦 экспорт данных в JSON
* 📊 экспорт данных в CSV

## ⚙️ Как работает

1. Расширение получает URL активной вкладки.
2. Из URL извлекается домен.
3. DNS Peek отправляет запросы через DNS-over-HTTPS.
4. Получает DNS-записи домена.
5. Для найденного IP получает ASN, провайдера и геолокацию.
6. Анализирует DNS и ASN для определения известных CDN.
7. Показывает результат в popup.

## 🚀 Установка в Firefox

Склонируй репозиторий:

```bash
git clone https://github.com/JafxZero/DNS-Peek.git
```

Перейди в папку:

```bash
cd DNS-Peek
```

В Firefox открой:

```text
about:debugging
```

Далее:

```text
This Firefox
→ Load Temporary Add-on
→ manifest.json
```

После этого расширение появится в Firefox.

## 🧪 Использование

1. Открой любой обычный сайт.

Например:

```text
https://github.com
```

2. Нажми на иконку **DNS Peek**.

3. Расширение автоматически определит домен и загрузит доступную DNS-информацию.

## 🌐 DNS-записи

Расширение поддерживает:

| Тип     | Назначение                                 |
| ------- | ------------------------------------------ |
| `A`     | IPv4 адрес                                 |
| `AAAA`  | IPv6 адрес                                 |
| `CNAME` | каноническое имя                           |
| `MX`    | почтовые серверы                           |
| `TXT`   | SPF, верификации и другие текстовые записи |

---

## 🔒 CDN detection

DNS Peek пытается определить популярные CDN по ASN и DNS-записям.

Поддерживаются, например:

* Cloudflare
* Fastly
* Akamai
* Amazon CloudFront
* Microsoft Azure CDN / Front Door
* CDN77

При этом сообщение:

```text
CDN не обнаружен
```

не означает, что CDN гарантированно отсутствует.

Это означает только то, что расширение не смогло определить известный CDN по доступным данным.

---

## 🕘 История

DNS Peek хранит небольшую локальную историю проверок через:

```javascript
browser.storage.local
```

История хранится только в браузере пользователя.

Расширение не использует отдельную базу данных и не отправляет историю на собственный сервер.

## 🔐 Безопасность

DNS Peek работает только с публично доступной информацией:

* DNS-записями
* публичными IP-адресами
* ASN
* публичной геолокацией IP

Проект не предназначен для взлома, обхода защиты или получения неавторизованного доступа к системам.

Если сайт находится за CDN, DNS Peek показывает публично доступную инфраструктуру, которую возвращает DNS.
